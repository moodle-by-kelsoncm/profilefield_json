Instalação
==========

Passo a Passo
-------------

1. Acesse o diretório de campos de perfil da sua instalação Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/user/profile/field

2. Clone o repositório nomeando a pasta como `json`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/profilefield_json.git json

3. Acesse **Administração do site > Notificações** para concluir a atualização no banco de dados.
