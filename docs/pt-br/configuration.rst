Configuração
============

Criando o Campo de Perfil
-------------------------

1. Acesse **Administração do site > Usuários > Contas > Campos personalizados do perfil**.
2. No menu suspenso **Criar um novo campo personalizado**, selecione **JSON**.
3. Defina o nome do campo, nome de exibição, regras de visibilidade e, opcionalmente, o modelo **JSON Schema** de validação.
4. Salve as alterações.
