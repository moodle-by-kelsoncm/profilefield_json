Visão Geral - moodle-profilefield_json
======================================

O **moodle-profilefield_json** é um plugin de campo personalizado de perfil de usuário que permite armazenar, visualizar e editar dados no formato **JSON** com interface gráfica interativa baseada no JSONEditor e validação por **JSON Schema**.

Recursos Principais
-------------------

- **Visualização & Edição Interativa**: Editor em árvore ou visualização em código JSON com destaque sintático.
- **Validação com JSON Schema**: Valida a estrutura dos dados antes da persistência para garantir conformidade técnica.
- **Padrão Aberto**: Armazenamento compatível com integrações REST e GraphQL.
